# Decisions log

Choices made during the build where the spec was ambiguous, out of date, or changed by the owner. Newest last.

| Date | Decision | Reason |
|---|---|---|
| 2026-11-08 | **ImageKit instead of Cloudinary** for all images and the resume. Requested by Abid. `MediaService` interface kept (`src/server/services/media.ts`), so another provider can be swapped in. | Owner's choice. Implemented with ImageKit's REST API directly (no SDK) to keep the dependency surface small. |
| 2026-11-08 | ImageKit **folder layout**: `{root}/profile`, `{root}/resume`, `{root}/games/<slug>/cover`, `{root}/games/<slug>/screenshots`, `{root}/testimonials`, `{root}/seo`, `{root}/library` (root = `IMAGEKIT_ROOT_FOLDER`, default `/najeeb-portfolio`). | Owner asked for "subdirectories for each project/samples". The game folder uses the slug at upload time; files are referenced by `fileId`, so later slug changes don't break anything. |
| 2026-11-08 | **Single resume.** Uploading a new resume deletes the previous file(s) from ImageKit and the media library, and sweeps the `/resume` folder for strays. The resume saves immediately (not via the profile Save button). | Owner requirement: "new one save should delete the old and upload the new one only". |
| 2026-11-08 | Uploads go **browser → ImageKit directly** (signed with short-lived token/expire/signature from `/api/upload/auth`), then `registerUpload` re-checks the file server-side (folder, MIME type, size, optional storage cap) and deletes it if invalid. | ImageKit's client signature can't restrict folder/size, so the server verifies after upload. Direct upload avoids Vercel's 4.5 MB body limit. |
| 2026-11-08 | Optional `IMAGEKIT_MAX_STORAGE_MB` cap (refuses uploads beyond it; shown in Media). Both `IMAGEKIT_URL_ENDPOINT` and `NEXT_PUBLIC_IMAGEKIT_URL_ENDPOINT` are accepted. | These were already in the owner's `.env.local`. |
| 2026-11-08 | **Seed uses the real resume data** (email, LinkedIn, Coursera, education, the 6 resume projects + 3 itch.io games, skills, languages) instead of the spec's placeholders. Only the 2 itch.io game descriptions without resume detail and the skill levels remain placeholders (flagged in the Setup checklist). Phone number is **not** published by default. | The resume PDF in `docs/reference/` is authoritative and avoids "your.email@example.com" on the live site. Phone is personal; Najeeb can add it in Profile → Contact. |
| 2026-11-08 | Seed uploads `docs/reference/Najeeb Ullah_2.pdf` as the initial resume when ImageKit is configured and no resume exists. | Site has a working "Download CV" from day one. |
| 2026-11-08 | Extra fields/options (optional, small): `profile.languages`; experience type `project`; social platform `coursera`; game link kind `github`. | Needed to represent resume content faithfully. |
| 2026-11-08 | **Next.js 16**: `cacheComponents` is **off**; public reads use `unstable_cache` with tags; mutations call `revalidateTag(tag, { expire: 0 })` (helper `expire()` in `src/server/revalidate.ts`). | Cache Components would require Suspense around every cookie-reading admin page. `{ expire: 0 }` makes changes visible on the very next request (the spec wants "within seconds"). |
| 2026-11-08 | `middleware.ts` is named **`src/proxy.ts`** (Next 16 rename). Auth.js config is split: `auth.config.ts` (no DB, used by the proxy) and `auth.ts` (credentials + DB). `sessionVersion` is checked in `getAdmin()` (every admin page/action) rather than in the JWT callback. | Keeps the proxy free of DB access; every server action still re-checks the session (defence in depth). |
| 2026-11-08 | Login rate limit/lockout is enforced inside `authorize()` (so it also covers direct POSTs to `/api/auth/callback/credentials`): 5 failures per IP+email per 15 min, plus a per-user lock for 15 min. | Spec §6/§7.4. |
| 2026-11-08 | Mongoose schemas are built **without `InferSchemaType`**; document shapes are hand-written interfaces in `src/server/models/index.ts`. | Mongoose 9's type inference on nested schemas exhausted the TypeScript compiler (OOM). |
| 2026-11-08 | All 4 font pairs' `next/font` **variable classes are applied** on `<html>`; `--font-head/--font-body` select the pair. | Variable classes only define CSS custom properties, so unused families are never downloaded (`preload: false`). This lets the live preview switch fonts instantly. |
| 2026-11-08 | Theme CSS is emitted as a `<style>` (`:root{…}`) rather than `<html style>`; the preview overrides it with `html:root{…}` and postMessage sets inline vars. Visitor toggle emits `[data-visitor-mode="dark"/"light"]` sets; a tiny pre-paint inline script applies the saved choice. | No flash of the wrong theme, and the preview can override cleanly. |
| 2026-11-08 | Derived tokens are computed in TypeScript; extra derived tokens (`--cover-to`, `--primary-deep`, `--primary-light`, `--glass`, `--glass-strong`, `--bg-glass`) replace the prototype's `color-mix()` usage. | PRD §7.6: don't rely on `color-mix()`. (Admin-only Tailwind opacity modifiers still use it; that's acceptable for the admin.) |
| 2026-11-08 | **Scroll reveals use CSS + one IntersectionObserver** (`RevealObserver`), not Framer Motion. Motion is used for the games filter layout animation. Content is only hidden when the pre-paint script adds `.js`, so it's never invisible without JavaScript. Hero uses a CSS entrance animation (no JS → good LCP). | Smaller public JS bundle and better LCP than per-element motion components. |
| 2026-11-08 | Profile socials and stats are edited inside the Profile form (one Save) instead of separate upsert/delete actions. | Simpler UX with the shared save bar; drag-reorder still works. |
| 2026-11-08 | `play_click` analytics are stored in our own `playclicks` collection (TTL 90 days) via `/api/track`, when SEO → Analytics is on. Vercel Web Analytics loads only if `NEXT_PUBLIC_ANALYTICS=1` too. | Vercel custom events require a paid plan; this keeps it free. |
| 2026-11-08 | The home page shows genre filter chips for the games shown on the home page (first N); `/games` shows all. | Avoids chips that would filter to an empty grid. |
| 2026-11-08 | Dynamic OG image is a route (`/og`, `/og?slug=…`) and the favicon is `/favicon`, instead of `opengraph-image.tsx` / `icon.tsx`. | File-based metadata would override an uploaded OG image / favicon. |
| 2026-11-08 | Deleting a game also deletes its cover/screenshots from ImageKit **unless they're used elsewhere** (the confirm dialog says so). | Keeps ImageKit storage clean; matches the single-source-of-truth idea. |
| 2026-11-08 | The SEO page's Google-result mockup uses Google's own colours (hard-coded). | It's a picture of Google's UI, not themed site UI. |
| 2026-11-08 | E2E tests run against a production build on port 3100 backed by `najeeb_portfolio_test` (seeded with `--force`; rate limits/messages cleared in `globalSetup`), with uploads disabled and emails logged. | Never touches the dev/prod database. |
| 2026-11-08 | Cloudflare Turnstile is supported behind `TURNSTILE_SITE_KEY`/`TURNSTILE_SECRET_KEY`. If enabled, add `https://challenges.cloudflare.com` to `script-src` and `frame-src` in `next.config.ts`. | Optional per spec; CSP not widened by default. |
